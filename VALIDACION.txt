VALIDACIÓN DE LA INTEGRACIÓN

Resultado: 388 comprobaciones de integración y 63 comprobaciones de carga
de datos aprobadas.

Se verificó:
- El chequeo de Django con las cinco aplicaciones y sus rutas reales.
- La compilación de las 46 plantillas.
- La respuesta de las 111 rutas con nombre, incluidos los rechazos esperados
  por falta de permiso o por utilizar un método HTTP no permitido.
- Registro, inicio y cierre de sesión, edición de perfil y seguimiento.
- Publicaciones, comentarios, reacciones, categorías y colecciones.
- Actualización de los resúmenes embebidos al editar una publicación.
- Preferencias personales y generación de recomendaciones sin duplicados.
- Mensajes privados, grupos, foros, miembros y bloqueos.
- Creación de reportes desde comunidad y resolución desde administración.
- Roles, actuaciones administrativas y control del sistema.
- Eliminación con confirmación, comprobaciones de propietario y protección CSRF.
- Documentos de las 14 colecciones frente a sus JSON Schema, usando validación
  local con tipos BSON; también se probaron documentos incorrectos.
- Carga repetida de ejemplos sin duplicar documentos.
- Carga de ocho fotografías con índices únicos activos en la base simulada.
- Respuesta HTTP y contenido completo de los ocho archivos JPEG.
- Conservación de contraseñas, biografías y preferencias al repetir la carga.
- Ampliación de la carga anterior conservando sus documentos y contraseñas.
- Rechazo antes de insertar si falta el administrador, una fotografía o
  existe una cuenta de ejemplo ocupada por otro correo.
- Conservación de fechas embebidas al guardar varias veces.
- Ausencia de ForeignKey en los modelos de las aplicaciones.
- Sintaxis de Python, ausencia de comentarios y ausencia de docstrings.

Entorno utilizado:
Python 3.12 del entorno de revisión; dependencias de requirements.txt.
MongoDB simulado con mongomock. Los esquemas se comprobaron localmente con
jsonschema y los tipos BSON de PyMongo.

Limitaciones pendientes:
No se ejecutó un servidor MongoDB real: su arranque fue rechazado por una
restricción del entorno. Por ello aún debe comprobarse preparar_base y el
validador del servidor contra la instalación que utilizará el grupo.

No se completó una inspección visual en navegador: la descarga del navegador
de pruebas no estuvo disponible. Las pantallas sí se renderizaron mediante
Django. Debe revisarse su presentación en el navegador del equipo final.

La instalación recomendada para presentar es el entorno Python 3.10 que ya
utilizaba el proyecto; esa versión de Python no estaba disponible aquí.

Para repetir las comprobaciones aisladas:
python -m pip install -r requirements_pruebas.txt
python pruebas/verificar_integracion.py
python pruebas/verificar_carga.py

Las pruebas utilizan una base simulada, no la conexión MongoDB del usuario.
